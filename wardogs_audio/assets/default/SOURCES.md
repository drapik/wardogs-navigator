# Локальный голосовой пакет по умолчанию

Пакет сгенерирован офлайн из встроенных фраз навигации и WRC этого проекта и обеспечивает базовую озвучку, когда системный голос недоступен.
WAV — моно, 24 кГц, PCM16. Во время работы только воспроизводится звук: модель не загружается, сеть и голосовые пакеты Windows не нужны.

- Модель генерации: [hexgrad/Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M), по заявлению авторов — Apache-2.0.
- Китайский голос: стандартный голос `zf_xiaoxiao` из исходного проекта.
- Офлайн-преобразование: [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx), MIT; китайский фронтенд Misaki. Среда генерации и модель с программой не распространяются.
- Скрипт генерации: `tools/make_default_voice_pack.py` в репозитории; нужны отдельная среда Kokoro и локальные файлы модели.
- Фразы и сгенерированное аудио предоставляются на условиях Apache-2.0 этого проекта; это не официальные записи игры.

`manifest.json` сопоставляет исходные фразы с аудио. Полные фиксированные фразы сопоставляются в первую очередь, динамические числа собираются по китайским разрядам.
Непокрытый пользовательский текст вызывает явную ошибку и не подменяется другим содержимым.

## Сопровождение числовых записей

В 0.7.2 заново сгенерированы числа и единицы расстояния и добавлены 36 полных числительных: «десять»–«девяносто», «сто»–«девятьсот»,
«тысяча»–«девять тысяч», «десять тысяч»–«девяносто тысяч» (по-китайски). Во время работы по-прежнему действует сопоставление по самой длинной фразе,
например 250 м собирается из «двести», «пятьдесят», «метров», а дробная часть читается по цифрам.

Короткие числа при отдельной генерации могут получать лишние слоги. Скрипт использует контекст «Сейчас читаю число, число, чтение окончено.» (по-китайски),
вырезает число по длительностям фонем модели и сохраняет соседние паузы, чтобы не отрезать начало слова и не захватить следующую фразу.
Скорость 0,8 используется только при офлайн-генерации чисел, настройка скорости в программе действует как обычно.

Используется [официальный ONNX-экспорт с выводом длительностей](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1)
тех же весов Kokoro-82M v1.0 (`kokoro-v1.0.onnx` из этого выпуска); он должен давать выход `duration` и поддерживать дробный `speed`.
Проверенная среда генерации: kokoro-onnx 0.5.0, Misaki 0.7.4, ONNX Runtime 1.27.0,
файл голосов — по-прежнему `zf_xiaoxiao` из `voices-v1.0.bin`.

```powershell
python tools/make_default_voice_pack.py --model <локальный путь к модели> --voices <локальный путь к голосам> --refresh-numbers
```

Команда обновляет записи чисел и единиц, сохраняя остальные фразы. После пересоздания проверьте в реальной склеенной озвучке целые числа,
числа с нулями, дроби, метры/километры и слитное чтение WRC; проверка одного формата WAV не гарантирует правильного произношения.
Модель, среда генерации и инструменты приёмки с распознаванием речи не входят в зависимости программы и в поставку.
