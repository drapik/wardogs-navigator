# Конфигурации сообщества для BAKURANI

ID карты: bakurani. Размещайте пакет конфигурации в каталоге «ваш_логин_GitHub/имя_пакета/» — с README.md и экспортированными программой JSON.

Присланных игроками конфигураций пока нет. Порядок публикации и импорта — в [общем описании](../README.md), описание заполняйте по [шаблону](../SUBMISSION_TEMPLATE.md).

| Пакет конфигурации | Автор | Тип содержимого | Объём проверки | Версия программы |
|---|---|---|---|---|

После проверки и слияния сопровождающий добавляет в таблицу относительную ссылку; непроверенное содержимое явно помечается «не проверено». Перед импортом сети дорог или избранного переключитесь на BAKURANI.
