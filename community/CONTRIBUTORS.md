# Участники — авторы конфигураций сообщества

Здесь отмечается принятый вклад: дороги, маршруты, легенды, исправления по результатам проверки в игре и общие описания; ценность не измеряется строками кода. Помимо автоматического учёта GitHub, авторство сохраняется в этом списке и в README каждого пакета конфигурации.

Принятых конфигураций сообщества пока нет; вымышленные участники заранее не вносятся.

| Участник | Вклад и ссылка на конфигурацию | PR слияния |
|---|---|---|

Сопровождающий вносит запись после фактического слияния или подтверждает её в том же PR, который будет принят. Совместный вклад подписывается каждым автором отдельно, при улучшении существующей конфигурации сохраняется исходный автор. Для одного аккаунта можно записать несколько вкладов без повторных одноимённых строк.

Для автоматического учёта GitHub нужны корректный автор коммита с привязанной почтой и слияние коммита в ветку по умолчанию; график Contributors показывает только первые 100 человек, а список может обновляться с задержкой. См. [справку GitHub](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors).

Упоминание здесь не даёт автоматически права записи или слияния в репозиторий.
