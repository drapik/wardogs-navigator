# Ресурсы карт

Необходимые для работы ресурсы поставляются вместе с исходниками. `maps.json` описывает для трёх карт размеры, подложку, признаки определения позиции, сеть дорог по умолчанию и исходные файлы; при запуске загружаются признаки только текущей карты.

| Карта | Размер изображения | Изображение и признаки | Сеть дорог по умолчанию |
|---|---|---|---|
| OZETI | 1595 × 1451 | `ozeti.png`, `ozeti-features.npz` | `default_project.json` |
| BAKURANI | 2047 × 2048 | `maps/bakurani/map.png`, `features.npz` | `maps/bakurani/project.json` |
| ZESTAFONA | 2048 × 1779 | `maps/zestafona/map.png`, `features.npz` | `maps/zestafona/project.json` |

Фиксированное преобразование координат OZETI хранится в `map-source.json`; область обрезки, масштаб и центр диагностического примера двух других карт — в их `source.json`. `legacy-road-seed.json` служит для распознавания и миграции ранних сетей дорог по умолчанию и не содержит пользовательской конфигурации.

`game-coordinates.json` хранит аффинное преобразование игровых x/y в пиксели текущей подложки; используются `bounds`, `tileBounds` и 100 м на единицу координат из указанных исходных карт. Сначала координаты пересчитываются в диапазон полной карты z5 размером 8192 пикселя и из них вычитается текущее начало обрезки, затем применяется `reference_to_map` каждой карты; игровая y растёт на север, а пиксельная y подложки — вниз. Ввод координат не меняет пользовательскую сеть дорог, масштаб и формат хранения проекта. Для BAKURANI преобразование перепроверено по координатам перекрестия в игре и сопоставлению рельефа; две другие карты используют преобразования из своих исходных данных.

## Источники и границы лицензии

Открытая конфигурация карт взята из [apollyon-sys/wardogs-calculator](https://github.com/apollyon-sys/wardogs-calculator) под лицензией MIT, Copyright (c) 2026 Apollyon; полный текст лицензии сохранён в [wardogs-calculator-LICENSE.txt](wardogs-calculator-LICENSE.txt). Тайлы взяты из открытого набора данных `assets-v1` этого проекта, конкретные адреса записаны в исходных JSON.

В проекте выполнены обрезка, масштабирование, выравнивание координат OZETI, извлечение признаков изображения, извлечение дорог-кандидатов и частичное исправление связей. Дороги-кандидаты проверены в игре не полностью; изображения и данные дорог не гарантированно соответствуют каждому обновлению игры.

Дороги по умолчанию в 0.5.3 — данные, вручную доработанные сопровождающим в программе 2026-09-19: OZETI — 248 (основных 85, второстепенных 162, бездорожье 1), BAKURANI — 266 (основных 103, второстепенных 163), ZESTAFONA — 206 (основных 135, второстепенных 69, бездорожье 2). Обновлены геометрия, названия, категории и примечания дорог; подложки, признаки определения, координаты и масштаб прежние. Временные поездки и личное избранное пользователей в данные по умолчанию не входят.

Существующие пользователи могут обновить дороги по картам через «Разметка карты → Загрузить встроенную сеть дорог»; программа сначала сделает резервную копию конфигурации, сохранит прочую разметку и избранное и позволит отменить действие.

`sample_minimap.png` — увеличенный фрагмент открытой подложки OZETI около точки (505, 1245); `reference-crop.png` двух других карт тоже взяты из открытых подложек. ## Необязательная пересборка ресурсов

Команды ниже выполняются из корня проекта Python-интерпретатором с установленными зависимостями. Процесс скачивает из сети открытые тайлы, сохраняет промежуточные результаты в `research/` и обновляет ресурсы в `assets/`; пользовательская конфигурация не меняется. Для обычного запуска и сборки это не требуется.

Для OZETI используется опубликованное преобразование координат, чтобы не сдвинуть координаты существующих дорог и избранного:

```powershell
python tools/fetch_clean_map.py --map ozeti --all-styles
python tools/prepare_clean_map.py
python tools/extract_roads.py
python tools/build_map_features.py
python tools/publish_map_assets.py
python tools/make_diagnostic_sample.py
```

Для двух других карт по отдельности:

```powershell
python tools/fetch_clean_map.py --map bakurani --all-styles
python tools/prepare_extra_maps.py --map bakurani
python tools/extract_extra_roads.py --map bakurani
```

Для ZESTAFONA замените `bakurani` на `zestafona`. После обновления данных проверьте границы карты, мосты и связи дорог, запустите тесты и самопроверку программы. Открытые фрагменты-примеры подтверждают только цепочку обработки данных; определение позиции по скриншотам игры и реальную проходимость нужно проверять отдельно.
