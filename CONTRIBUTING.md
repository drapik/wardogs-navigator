# Участие в разработке

Приветствуются исправления ошибок, доработка дорог и легенд, улучшение определения позиции по изображению и удобства навигации. Команды установки окружения, тестов и сборки — в [README](README.md).

## Сообщения об ошибках

Укажите версию программы, версию Windows, карту, масштаб мини-карты и минимальные шаги воспроизведения. К проблемам определения позиции можно приложить PNG/JSON последнего неудачного кадра из «Настройки → Сохранить диагностику определения» (если не удался сам захват — только JSON); сохраните их до повторного включения определения или смены карты и перед публикацией проверьте, нет ли там данных игрока или меток, которые вы не хотите показывать. Для проблем с дорогами или избранным по возможности приложите экспорт только с нужным содержимым.

## Изменения и проверка

Если вы только делитесь конфигурацией игрока, начните с [руководства с иллюстрациями](community/新手投稿图文教程.md) или [текстового руководства](community/新手投稿纯文字教程.txt) (оба на китайском); структура каталогов описана в [библиотеке конфигураций сообщества](community/README.md), полный формат описания — в [шаблоне](community/SUBMISSION_TEMPLATE.md), менять код программы не нужно. Поместите экспортированный программой JSON в каталог нужной карты, автора и пакета конфигурации и укажите подходящую версию, проверенный объём и способ импорта. Здесь можно присылать специально подготовленные общие конфигурации; под «личной конфигурацией» ниже понимаются локальные настройки, личные резервные копии и неразобранные каталоги пользовательских данных.

Конфигурация — тоже вклад. После проверки автор и ссылка на конфигурацию записываются в [список участников сообщества](community/CONTRIBUTORS.md). При слиянии авторство сохраняется; для совместной работы сохраняются точные сведения о соавторах, чужие файлы не копируются в новый коммит только от имени сопровождающего. Упоминание в списке участников не даёт права записи в репозиторий.

- Сохраняйте подход: определение позиции по снимку экрана, отображение в отдельном окне и ручное вождение. Не добавляйте доступ к памяти игры, внедрение кода, автоматизацию ввода или обход античита.
- Задавайте отдельный каталог конфигурации через `WARDOGS_NAV_DATA`, чтобы запуски при разработке не писали в повседневную конфигурацию. Например, в PowerShell: `$env:WARDOGS_NAV_DATA = "$PWD\user-data\dev"`.
- При изменении маршрутизации, конфигурации или переключения карт прогоните соответствующие тесты. После изменений интерфейса проверьте взаимодействие и в нативном окне Windows; тесты без дисплея не доказывают работу реального захвата и совместимость с игрой.
- Координаты сети дорог и ID карт должны совпадать. Программа больше не различает статус подтверждения дорог; фактически проверенный и непроверенный объём описывается в README пакета конфигурации, без оснований не помечайте мины, противников или проходимость дорог.
- Не коммитьте личную конфигурацию, диагностику определения, каталоги сборки и локальные резервные копии. Для новых материалов укажите источник и применимую лицензию.

Описание коммита должно сообщать конкретную проблему, итоговое поведение и фактически выполненную проверку. Вклад предоставляется по лицензии проекта Apache-2.0; сторонние материалы сохраняют исходное авторство и лицензию.
