# WARDOGS Navigator

> Это русская версия форка [drapik/wardogs-navigator](https://github.com/drapik/wardogs-navigator). Оригинальный проект — [greatredo/wardogs-navigator](https://github.com/greatredo/wardogs-navigator), исходный китайский README — [README.zh.md](README.zh.md). Аудит безопасности форка — [SECURITY_AUDIT.md](SECURITY_AUDIT.md).

Локальный навигатор для Windows для наземной техники в WARDOGS: определение позиции по мини-карте на экране, наложение на большую карту в бою и навигация горячими клавишами, рисование дорог по категориям, запись пройденного маршрута, избранные маршруты целиком, объезд опасных зон, заданных рамкой, непрерывные рейсы туда-обратно, обычные и раллийные подсказки, офлайн-озвучка. Встроены три карты — **OZETI, BAKURANI, ZESTAFONA**; текущая версия — **0.7.4 (бета)**, интерфейс в этом форке переводится на русский.

Оригинальный код программы и документация распространяются по лицензии [Apache-2.0](LICENSE). Права на картографические материалы и сторонние компоненты описаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Проект неофициальный: разработчик игры явно не одобрял его использование в сети или распространение; открытая лицензия не означает разрешения от разработчика игры.

## Запуск

В этом форке готовые сборки `.exe` не публикуются: программа запускается из исходников или собирается самостоятельно. Целевая платформа — Windows 10/11 x64. Команды выполняются в корне проекта:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Собрать переносимую папку с `WardogsNavigator.exe` можно скриптом `build.ps1` (см. раздел «Разработка и сборка»). В собранной папке программу запускают через `WardogsNavigator.exe` или `Запуск.cmd`; папку `_internal` рядом с ними удалять нельзя, Python для собранной версии не нужен.

После запуска сразу открывается наземная навигация.

Числовые поля и выпадающие списки в окнах настроек и свойств больше не меняют значение колесом мыши: вводите значение, нажимайте стрелки или выбирайте вариант. Колесом по-прежнему прокручиваются страницы и масштабируется карта.

## Первое использование

1. Выберите текущую карту игры вверху окна. **Оставьте текущий полноэкранный режим игры**; мини-карта всегда ориентирована на север. Рекомендуется такой масштаб мини-карты, при котором хорошо видны окрестные дороги и рельеф. Прилагаемый `Пример_миникарты.png` — фрагмент открытой подложки только для самопроверки определения позиции по картинке; это не скриншот игры и не рекомендуемый масштаб.
2. Нажмите «Выделить мини-карту», выберите монитор и обведите изображение карты на статичном снимке экрана. Координаты захвата задаются в физических пикселях, поддерживаются разные мониторы и DPI. Выделяйте только саму карту, без рамки и других элементов HUD. Стрелка игрока по умолчанию находится в центре области захвата; если она смещена, поправьте якорь X/Y в процентах в «Настройках».
3. Нажмите «Включить определение позиции» и убедитесь, что позиция попадает на реальный рельеф. Можно сначала проверить алгоритм офлайн через «Настройки → Проверить определение по картинке», выбрав скриншот мини-карты; проверка по картинке не запускает навигацию в реальном времени.
4. Выберите пункт назначения на общей карте. Стартовую точку можно задать кнопкой «Задать старт на карте», правым кликом по карте или «Использовать текущую позицию»; синюю метку можно перетаскивать. Стартовая точка также служит конечной точкой обратного пути. Если старт не задан, после нажатия «Начать навигацию» и получения надёжной позиции он автоматически ставится в текущее место; существующий старт не перезаписывается. Включите нужные категории дорог и начните навигацию. Пункты назначения можно добавлять в избранное и выбирать повторно; при заданном старте полный маршрут можно посмотреть и без определения позиции.
5. Для объезда нажмите **«Выделить опасную зону»** и, удерживая кнопку мыши, растяните прямоугольник. Маршрут автоматически обходит участки, пересекающие прямоугольник; перетаскивание центра перемещает зону, правого нижнего угла — меняет размер. Если дороги не связаны, программа прямо сообщает об этом и не достраивает прямую через неизвестную местность.
6. Можно добавить промежуточные точки и перетаскивать их — маршрут пройдёт через них по порядку. В режиме «туда-обратно» по прибытии появится подсказка развернуться, и направление переключится между «туда» и «обратно». Изменение пункта назначения в пути не меняет стартовую точку; изменение старта на пути «туда» корректирует будущую конечную точку обратного пути, а на пути «обратно» — сразу пересчитывает текущий обратный путь. Навигация продолжается от текущего положения машины. Стартовая точка сохраняется в конфигурации текущей карты, поддерживает отмену, импорт и экспорт; управляет машиной сам игрок.
7. Во время навигации маршрут по умолчанию накладывается на мини-карту игры: бледная линия — весь маршрут рейса, яркая — оставшаяся часть, которая укорачивается по мере движения; после разворота в режиме «туда-обратно» отображается новое направление. Главное окно можно свернуть — отдельный значок и маршрут остаются на экране; при потере позиции или остановке навигации маршрут скрывается.

Чтобы перед каждым боем задать маршрут заново, на первой вкладке **«Навигация → Пункт назначения и промежуточные точки»** или на **панели над картой** нажмите «Очистить промежуточные точки» или «Очистить опасные зоны». Кнопки удаляют соответствующие объекты только текущей карты, сохраняя пункт назначения, дороги и избранное; после очистки маршрут перестраивается автоматически, вернуть всё можно кнопкой «Отменить» вверху или Ctrl+Z. Если удалять нечего, кнопки неактивны.

Чтобы закончить поездку, в тех же местах нажмите **«Сбросить текущий маршрут»**: навигация и озвучка останавливаются, удаляются старт, пункт назначения, все промежуточные точки, предпросмотр маршрута и линия на мини-карте текущей карты, а также сбрасываются загруженный избранный маршрут и текущий рейс «туда-обратно». Значок навигации сохраняет прежнюю видимость; если он был виден, появится сообщение «Маршрут сброшен». Результат сохраняется автоматически, и после перезапуска старые точки не вернутся; сохранённые дороги, избранные пункты и маршруты, легенды, опасные зоны и правила маршрутов остаются. Случайное нажатие можно отменить — настройки поездки восстановятся, но навигацию придётся запустить вручную. «Стоп» только приостанавливает навигацию и сохраняет предпросмотр маршрута; чтобы убрать старый маршрут, используйте «Сбросить текущий маршрут».

## Карты и редактирование дорог

- **Список карт вверху** переключает OZETI, BAKURANI и ZESTAFONA. При переключении текущая карта сохраняется, загружаются дороги, избранное, легенды, опасные зоны, пункты назначения и масштаб новой карты, старая позиция и маршрут сбрасываются, озвучка останавливается. Чтобы продолжить, снова включите определение позиции и начните навигацию; последний выбор запоминается до следующего запуска. В памяти держатся признаки определения позиции только текущей карты.
- Все три карты используют открытые подложки без меток союзников. В 0.5.3 включена дорожная сеть, вручную доработанная сопровождающим 2026-09-19: OZETI — 248 дорог, BAKURANI — 266, ZESTAFONA — 206, с категориями «основная дорога», «второстепенная дорога» и «бездорожье». Исходная сеть получена извлечением из изображения с частичным исправлением связей и может дорабатываться вручную; покрытие и фактическая проходимость требуют проверки в игре.
- При первом запуске загружаются новые встроенные дороги. Существующая конфигурация сохраняется; чтобы перейти на новую сеть, выберите карту и подтвердите **«Разметка карты → Загрузить встроенную сеть дорог»**. Это заменяет все дороги карты, сохраняя избранные маршруты, пункты назначения, промежуточные точки, опасные зоны, легенды и правила, автоматически делает резервную копию и поддерживает отмену. Каждую карту нужно обновлять отдельно; если хотите сохранить свои дороги, сначала отдельно сохраните их через «Экспорт сети дорог», а затем при необходимости импортируйте с объединением.
- Золотой цвет — основные дороги, синий — второстепенные, светло-зелёный — бездорожье/офф-роуд. Все дороги на карте рисуются пунктиром, как неподтверждённые дороги в 0.5.0, — это только стиль отображения, статус подтверждения больше не различается. Маршрут навигации на основной карте и мини-карте игры по-прежнему рисуется сплошной линией. На всех трёх картах одинаково работают автопостроение, дорисовка, избранное и легенды.
- После сохранения или импорта дороги сразу участвуют в построении маршрута по своей категории, статус подтверждения задавать не нужно. Старый фильтр «Только проверенные» больше не действует, старые дороги и их геометрия сохраняются. Совместимые поля в формате конфигурации остаются, но не означают, что проходимость проверена; при публикации опишите в пояснении, что проверено в игре.
- В **«Навигация → Предпочтения дорог»** для каждой категории выбирается «Предпочитать / Обычно / По возможности избегать». Построение учитывает и расстояние, и предпочтения; при необходимости маршрут всё равно может пройти по нежелательной дороге, чтобы не разрываться, если вы хотите ехать в основном по бездорожью. Для бездорожья по умолчанию стоит «По возможности избегать»; отмеченные в старой конфигурации типы становятся «Обычно», неотмеченные — «По возможности избегать», дороги и разметка сохраняются. Предпочтения влияют на автовыбор пути, подключение избранного и объезд опасных зон; через опасные зоны проезд всегда запрещён. Изображение не доказывает проходимость участков бездорожья и не показывает мины.
- Нажмите **«Рисовать дорогу»** над картой, выберите основную, второстепенную дорогу или бездорожье и кликайте по точкам там, где хотите ехать. Enter, двойной клик или «Готово» — сохранить, Backspace или «Шаг назад» — удалить последнюю точку, Esc — отменить. При сохранении можно указать название, категорию и примечание.
- В режиме **«Перемещение / выбор дороги»** клик по дороге выделяет её и показывает узлы; перетаскивание узлов меняет трассу, двойной клик открывает редактирование названия, типа и примечания. Правый клик по дороге позволяет изменить или удалить её целиком, правый клик по узлу — удалить точку. Список синхронно выделяет соответствующую дорогу. Ctrl+Z — отмена, Ctrl+S — сохранение.
- При рисовании точки по умолчанию прилипают к существующим участкам в пределах 8 пикселей карты; для бездорожья или параллельных просёлков «Прилипание к дорогам» можно отключить. Перемещение общего узла обновляет соседние дороги того же уровня, а заземлённый въезд на мост тянет за собой связанные наземные узлы. В местах пересечения нужно явно ставить соединительный узел — простое пересечение линий не создаёт связи.
- **Свойство дороги «Мост»** переводит её на уровень моста, сохраняя категорию и предпочтения. Дорога под мостом остаётся обычной: даже при совпадающих координатах узлов уровни не соединяются и пересечение не объявляется перекрёстком. Отмечайте только реальные участки мостового полотна; если полотно состоит из нескольких дорог, отметьте мостом все, а промежуточные стыки оставьте «не заземлёнными».
- **«Начало заземлено / Конец заземлено»** по умолчанию выключены и включаются только на реальных въездах на мост или съездах на землю. Они относятся к двум концам дороги в порядке рисования; окно свойств показывает координаты, а у выделенного моста на карте отмечаются начало, конец и состояние заземления. Въезд на мост может подключаться к середине наземного участка. Снятие флага «Мост» возвращает обычные правила наземных соединений. В существующей сети мосты автоматически не угадываются — их нужно размечать вручную; если старт, финиш или промежуточная точка попали точно на место, где мост и дорога под ним совпадают, слегка сдвиньте точку на нужную дорогу и постройте маршрут снова.
- **«Разметка карты → Импорт сети дорог / Экспорт сети дорог»** позволяет делиться только дорогами и легендами. Импорт объединяется с существующими данными без дублей и не перезаписывает пункты назначения, опасные зоны и избранное. Библиотека содержит идентификатор карты, поэтому перед импортом переключитесь на ту же карту, чтобы координаты не попали на чужую. «Импорт конфигурации» вверху по-прежнему полностью заменяет данные соответствующей карты; при импорте другой карты текущая сохраняется и происходит автоматическое переключение, замену можно отменить.
- Старт, финиш и промежуточные точки притягиваются к доступным дорогам; смещение показывается в деталях маршрута. Конечная точка навигации — притянутая точка на дороге, последний отрезок через неизвестную местность не прокладывается. При слишком большом расстоянии построение отклоняется — дорисуйте соединяющую дорогу или поправьте точку.
- При обновлении данных подложки неизменённые старые встроенные дороги заменяются автоматически, а пункты назначения, опасные зоны, легенды и добавленные пользователем дороги сохраняются, с резервной копией `project-before-map-v2.json`. Если старые встроенные дороги изменялись или удалялись, исходная сеть сохраняется; заменить её можно вручную через «Разметка карты → Загрузить встроенную сеть дорог», предварительно сохранив копию.

## Избранные маршруты целиком

1. После построения нажмите «Навигация → В избранное», чтобы сохранить весь путь; это можно сделать и во время навигации. Избранное хранит конкретный путь и при повторной загрузке не перестраивается на более короткие дороги.
2. В **«Избранных маршрутах»** выберите маршрут и нажмите «Загрузить» или «Загрузить в обратную сторону» — одновременно задаются старт и пункт назначения для этого направления; посмотреть весь маршрут можно и без определения позиции. Старт можно затем изменить как конечную точку обратного пути. При начале навигации программа по дорожной сети подключается к ближайшему участку избранного маршрута у текущей позиции и далее ведёт по оставшемуся пути; при пересчёте после схода с маршрута заданный старт сохраняется.
3. Нажмите **«Нарисовать избранный путь»**, включите **«Прилипать к существующим дорогам»** и грубо отметьте по порядку движения старт, ключевые точки и финиш. Зелёный предпросмотр показывает полный путь, построенный по текущим правилам типов дорог и опасных зон; тип дороги берётся из существующей сети. Enter, двойной клик или «Готово» сохраняет путь из предпросмотра. Если прилипание невозможно, черновик сохраняется с объяснением причины — поправьте точки или правила.
4. Без прилипания путь сохраняется точно по точкам, и во время рисования для следующего отрезка можно выбрать основную, второстепенную дорогу или бездорожье. При включённом **«Создавать недостающие дороги по пути»** недостающие участки добавляются в общую сеть соответствующего типа и используются обычным автопостроением; без этого флага навигация по избранному работает, но в общую сеть ничего не добавляется. Выбор сохраняется вместе с избранным и не меняется после перезапуска, обратной загрузки или рейсов туда-обратно.
5. Избранное сохраняет исходный путь и загружается, даже если содержит типы «По возможности избегать». Подключение к избранному и локальный объезд опасных зон используют текущие предпочтения дорог; если подключиться не удаётся, программа прямо сообщает об ошибке. Выбор нового финиша или промежуточной точки на карте выходит из режима избранного и возвращает автопостроение.
6. **«Импорт избранного»** сначала показывает параметры: с прилипанием полный путь пересчитывается по текущей сети; без прилипания исходный путь сохраняется, и нужно выбрать «Создать общие дороги», «Только для избранного, без создания дорог» или использовать настройки каждого маршрута из файла. Для старых файлов без этих настроек выбор обязателен. Отмена или неудачное прилипание не меняют текущую конфигурацию; после импорта доступна отмена.
7. **«Экспорт избранного»** сохраняет для каждого маршрута полный путь, типы дорог по участкам, названия и ID, статус прилипания, флаг создания дорог и точки, использованные при прилипании, а также идентификатор карты, масштаб расстояний и все легенды. При повторном импорте можно использовать настройки из файла. Глобальные опасные зоны, правила дорог, пункты назначения и т. п. сохраняются через «Экспорт конфигурации» вверху; библиотеку дорог можно экспортировать отдельно. Удаление избранного не удаляет добавленные им общие дороги — их можно отдельно выделить и удалить на карте.
8. Свойства мостов и въездов сохраняются и передаются вместе с сетью, конфигурацией и избранным. При загрузке старого избранного действуют текущие настройки мостов; если старый путь поворачивал прямо в точке пересечения моста с дорогой под ним, программа предложит перестроить маршрут через реальный въезд. Подключение избранного, обратная загрузка, рейсы туда-обратно и объезд опасных зон также соблюдают уровни и не создают автоматически наземный «срез» для старого пути.

## Запись пройденного маршрута

Запись включается в **«Разметка карты → Запись маршрута»** и использует только надёжную позицию по мини-карте в реальном времени; запускать навигацию заранее не нужно.

- **Ручная запись**: нажмите «Начать запись», проедьте маршрут и нажмите «Завершить и добавить в сеть». Во время записи на карте программы показывается оранжевый трек; новая дорога по умолчанию получает тип «бездорожье», совпадающие с существующей сетью части пропускаются, а на пересечениях с наземными дорогами трек разбивается на отдельно редактируемые дороги. Пересечения под мостом не подключаются к мосту автоматически — соединяться могут только размеченные заземлённые въезды.
- **Автоматическая запись**: включите «Автоматически считать проезды и создавать дороги» — участок добавляется в сеть, когда число проездов по нему достигает минимума. По умолчанию **3 раза**, можно задать 1–100; считаются независимые проезды, проезд в обратную сторону тоже засчитывается, а стоянка и непрерывная позиция не дают повторного счёта. Новые соседние автоматически записанные участки продолжают наращиваться, на наземных пересечениях дороги остаются разбитыми; дороги, у которых вручную меняли свойства или узлы, больше автоматически не удлиняются.
- Трек прерывается при открытии большой карты, потере позиции, перерыве больше 2,5 секунды или заметном скачке позиции; после восстановления надёжной позиции по мини-карте начинается новый отрезок. Проверка определения по картинке не записывается. Добавление дорог не прерывает идущую навигацию или рейс туда-обратно; свойства можно редактировать, действие — отменить.
- Счётчики проездов и незавершённая ручная запись сохраняются по картам в каталоге пользовательской конфигурации `recordings/<идентификатор карты>.json` и переживают перезапуск; для продолжения записи нужно снова включить определение позиции. «Сбросить счётчики этой карты» обнуляет только автоматический счёт, сохраняя добавленные дороги и ручную запись. Автоматическая запись по умолчанию выключена.

## Большая карта в бою и горячие клавиши

1. Откройте большую карту в игре, затем «Настройки → Большая карта в бою → Выделить большую карту на этом экране» и обведите центральное изображение карты без рамки, координатной шкалы и подсказок управления. После подтверждения функция большой карты включится автоматически — затем включите определение позиции. Большая и мини-карта используют свои области в физических пикселях; после смены разрешения или масштаба интерфейса игры нужно выделить заново.
2. Пока позиция по мини-карте определяется нормально, большая карта не захватывается и не сопоставляется, мышь не читается, состояние горячих клавиш не проверяется. Большая карта проверяется только после первой неудачи распознавания мини-карты; наложение и горячие клавиши включаются, только когда большая карта распознана надёжно и игра на переднем плане. При кратковременной неудаче сопоставления остаются разметка предыдущего кадра и последний процент распознавания, сопоставление продолжается в фоне, и надпись «Распознавание…» больше не появляется; при восстановлении позиции по мини-карте, выключении определения, переключении окна или выделении области наложение снимается, а горячие клавиши отключаются.
3. На большой карте показываются бледный полный маршрут, яркий оставшийся, старт, пункт назначения, промежуточные точки, границы опасных зон, легенды, избранные пункты назначения и последнее положение машины; общая сеть дорог по умолчанию скрыта и включается в настройках. Окно наложения пропускает мышь насквозь и не мешает перетаскиванию, масштабированию и управлению в игре. При сильном приближении с недостатком рельефа используется отслеживание по ранее подтверждённому виду; если карта сразу открыта на максимальном приближении, сильно перекрыта или отслеживание прервалось, уменьшите масштаб для повторного распознавания.
4. Горячие клавиши принимаются, когда курсор находится в выделенной области большой карты; перед действием делается новый снимок для уточнения координат. Повторные действия ставятся в очередь, при временной неудаче сопоставления выполняется повтор, а если уточнить координаты за 6 секунд не удалось, действие отменяется с сообщением. Клавиши меняются в настройках (пустое поле — отключить) и применяются кнопкой «Сохранить горячие клавиши»; при конфликте регистрации показывается конкретное действие. По умолчанию:

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+N | Новая навигация в одно нажатие: последнее положение машины по мини-карте — новый старт, позиция курсора — пункт назначения, старые промежуточные точки удаляются |
| Ctrl+Alt+D | Изменить пункт назначения, сохранив старт |
| Ctrl+Alt+S | Изменить старт / конечную точку обратного пути |
| Ctrl+Alt+W | Добавить промежуточную точку |
| Ctrl+Alt+A | Добавить круглую опасную зону; радиус задаётся в настройках |
| Ctrl+Alt+Z | Отменить последнюю метку |
| Ctrl+Alt+C | Сбросить маршрут, старт, пункт назначения и промежуточные точки; видимость значка навигации сохраняется |

Поддерживаются сочетания Ctrl / Alt с буквами, цифрами, `[`, `]` или F1–F11. `*` и `Ctrl+*` можно ввести умножением на цифровом блоке или Shift+8 на основной клавиатуре; одиночная `*` работает без Ctrl / Alt. После изменения нажмите «Сохранить горячие клавиши»; если сохранить не удалось, сообщение появится вверху окна, а в «Настройки → Большая карта в бою» показываются последние полученные клавиши и результат обработки.

На случай, если игра не пропускает системные сообщения о горячих клавишах, в режиме большой карты на переднем плане программа также читает текущее состояние назначенных клавиш и убирает дубли с системными сообщениями; удержание срабатывает один раз, повторное срабатывание — после отпускания. Глобального перехвата клавиатуры нет, ввод в игру не отправляется. При сохранении диагностики определения позиции прикладываются источник и статус обработки последней горячей клавиши навигации, чтобы найти звено, которое не отреагировало.

Последнее положение машины хранится без ограничения по времени — в пределах одной карты до следующего надёжного определения по мини-карте; при переключении карты оно сбрасывается. Если положения машины ещё нет, «Новая навигация» сначала сохраняет пункт назначения, а после возврата на мини-карту и получения позиции автоматически ставит старт и строит маршрут. Пока открыта большая карта, прогресс машины и озвучка приостанавливаются; перетаскивание и масштабирование карты не сдвигают машину и старт. Если в пути изменить метки, после возврата на мини-карту продолжится прежний путь «туда» или «обратно». Информация о позиции в HUD синхронизирована с главным окном, в режиме большой карты показывается уверенность сопоставления; если навигация не идёт, после успешного повторного включения определения главный заголовок возвращается к «Ожидание».

Сеть дорог на большой карте включается в **«Настройки → Большая карта в бою → Показывать сеть дорог на большой карте»**; по умолчанию выключено, выбор запоминается. Во включённом состоянии дороги рисуются бледным пунктиром по категориям «основная», «второстепенная», «бездорожье», маршрут и метки — поверх. Это не зависит от видимости дорог на основной карте программы. И сеть, и наложение маршрута требуют надёжного сопоставления рельефа большой карты; по одним координатам перекрестия положение изображения не угадывается.

## Состояние слоя навигации

Если никаких действий не выполняется, крупно показывается **«Ожидание»**, а информация о позиции — отдельно. Сообщения о завершении записи, сбросе маршрута, остановке навигации, прибытии и смене режима держатся около **2 секунд**, затем показывается состояние текущей задачи; постоянные состояния — потеря позиции, ожидание позиции, сход с маршрута, ожидание возврата на дорогу — таймером не убираются.

Во время ручной записи без навигации крупно показывается **«Идёт запись маршрута»**; при одновременной навигации сохраняются подсказки поворотов и легенда, а статус записи постоянно показывается внизу. При потере позиции крупно остаётся «Позиция потеряна» с пометкой, что запись приостановлена; после восстановления статус записи возвращается автоматически. При открытии большой карты или выключении определения позиции также явно показывается пауза записи. После завершения появляется сообщение о завершении записи, а если новых участков нет — с объяснением причины; во время навигации или при постоянном предупреждении сообщение выводится внизу и не перекрывает навигацию или предупреждение. Начало ручной записи показывает слой навигации.

## Игровые координаты

- В «Навигация → Игровые координаты» можно ввести или вставить игровые координаты вида `x87.18, y33.31` (также принимается `87.18/33.31`) для пункта назначения, старта, промежуточной точки или новой навигации в одно нажатие. Пересчёт идёт по карте, выбранной вверху (**OZETI / BAKURANI / ZESTAFONA**); сами координаты не содержат названия карты, поэтому сначала выберите правильную карту. Показания под курсором под подложкой программы тоже выводятся в игровых координатах.
- «Настройки → Большая карта в бою → Читать координаты перекрестия, если рельеф не сопоставлен» по умолчанию включено и действует вместе с общим переключателем большой карты. Выделенная область должна включать перекрестие и текст x/y на карте; после включения определения позиции, если мини-карта не работает и рельеф большой карты тоже не сопоставлен, программа автоматически пытается прочитать координаты перекрестия. В этом случае HUD показывает «Координаты большой карты», и горячие клавиши остаются доступными; **без преобразования по рельефу наложение маршрута временно не рисуется**, а после восстановления сопоставления продолжается.
- Координаты читаются локальным английским OCR Windows, без интернета и GPU. Показание используется, когда оно стабильно два кадра подряд; после нажатия горячей клавиши держите перекрестие на месте — программа сверит позицию действия по новому кадру. Если текст слишком мелкий, перекрыт или компонент распознавания недоступен, значение не угадывается — используйте ввод координат. Пока мини-карта работает нормально, распознавание большой карты, OCR координат и отслеживание мыши не запускаются.
- Координаты перекрестия задают целевую точку; положение машины по-прежнему берётся с мини-карты. Без положения машины новая навигация в одно нажатие сначала сохраняет пункт назначения, а после возврата на мини-карту ставит старт и начинает. Отдельное «Сделать пунктом назначения» только сохраняет цель, навигацию нужно запустить кнопкой. Игровая команда «Отметить координаты» по правому клику пишет текст в поле ввода чата — его нужно выделить и скопировать самостоятельно; программа не читает чат и не отправляет сообщения.

## Сход с дороги и радиус прибытия

- Вдали от доступных дорог показывается «Вернитесь на дорогу», пересчёт приостанавливается, а пункт назначения, промежуточные точки и текущее направление рейса сохраняются. При приближении к дороге маршрут пересчитывается автоматически; если построить не удалось, поездка сохраняется — подъедьте к другой доступной дороге и попробуйте снова. «Радиус близости к дороге» в настройках по умолчанию 30 м; при возвращении используется чуть меньший радиус, чтобы на краю дороги состояние не переключалось туда-сюда.
- «Навигация → Радиус прибытия» задаётся в пределах 5–1000 м, по умолчанию остаются прежние 25 м. Центр круга — фактически заданная целевая точка; прибытие засчитывается, когда два надёжных определения подряд попали в радиус, — доезжать точно до проекции на дорогу не нужно. Действует и на пути туда, и обратно. Если радиусы в режиме туда-обратно перекрываются, повторное прибытие засчитывается только после выезда из радиуса только что достигнутой точки — чтобы при стоянке направление не менялось многократно. Если масштаб не откалиброван, расчёт идёт в единицах карты.

Координаты мыши читаются как физические экранные координаты Windows, без распознавания формы курсора. Запись видео подтверждает только соответствие рельефа; совпадение нарисованного игрой курсора с координатами Windows, глобальные горячие клавиши и совместимость с эксклюзивным полноэкранным режимом нужно проверять в реальной игре.

## Обычная навигация, ралли и озвучка

Режим ралли в интерфейсе и конфигурации обозначен как WRC. Он добавляет немного удовольствия в долгие перевозки и повторяющиеся рейсы за счёт легенды и голосовых подсказок в стиле штурмана.

- Обычный режим и WRC переключаются в «Навигация → Навигация и озвучка»; **«Просмотр подсказок»** показывает оба списка подсказок для одного маршрута и позволяет прослушать выбранную строку без входа в игру.
- **Обычная навигация** возвращает озвучку из 0.6.2: на каждой реально подключённой развилке звучит «На перекрёстке прямо, налево, направо, левее/правее», при старте и после перекрёстков — «Двигайтесь по текущей дороге ×× метров», а при приближении к перекрёстку — подсказка действия. Объединённые подсказки нескольких перекрёстков и напоминания о плавных изгибах из 0.6.3 убраны; простой изгиб дороги или смена её номера поворотом не объявляются. В **«Настройки → Обычная навигация»** остаются дистанция упреждения и упреждение в секундах по скорости. Ненарисованные развилки по сети определить нельзя — дорисуйте их.
- В **«Настройки → Общие подсказки вождения»** включается напоминание о развороте, для обычного режима и WRC. Если машина движется против маршрута не меньше ~20 м и 2 секунд, звучит «Движение в обратном направлении, развернитесь в безопасном месте» — один раз за эпизод, после исправления навигация продолжается. Оценка идёт по последовательным позициям, а не по изредка нераспознаваемому силуэту машины; дрожание на стоянке и короткий задний ход сразу не срабатывают. Исходный маршрут, конечные и промежуточные точки и состояние рейса сохраняются.
- **WRC** использует отдельный анализ кривизны, отфильтровывает мелкое дрожание ломаной и подсказывает «левый/правый 1–6», «прямой угол», «шпилька» и т. п.; **1 — медленный поворот, 6 — быстрый**. Значок одновременно показывает до трёх следующих элементов легенды, а озвучка может объединять их, например «левый три, не срезать, в правый шесть». Это лишь оценка по геометрии карты — по ней нельзя судить о предельной скорости машины.
- В «Разметка карты → Легенда WRC» можно добавлять «резкое торможение», «торможение», «гребень», «неровности», «прыжок», «сужение», «мост», «брод» и т. п., отмечать «длинный», «затягивается», «раскрывается», «не срезать» или «можно срезать», а также задавать свой текст озвучки. Резкое торможение, уклоны, срезку и т. п. нужно размечать вручную по результатам проверки; автооценка такие условия не придумывает. Ручные метки поворотов перекрывают оценку поблизости.
- При добавлении элемента легенды задаётся азимут въезда в прямом направлении (север 0°, восток 90°) и выбирается «в обе стороны / только прямо / только обратно». Для двусторонней метки в обратном направлении меняются местами «лево/право» и «затягивается/раскрывается». Направленные риски лучше ставить как «только прямо», а свой текст для прямого и обратного направления задавать отдельно. В окне редактирования доступны предпросмотр и прослушивание.
- В «Настройки → Обычная навигация / Легенда WRC» упреждение настраивается отдельно для каждого режима; у WRC есть ещё интервал слитного чтения. Упреждение = базовое расстояние + оценка скорости × секунды упреждения. Отдельный элемент легенды может переопределить базовое расстояние, 0 — использовать общее значение режима. В «Офлайн-озвучке» задаются голос, скорость и включение. Если позиция ненадёжна или прервана больше чем на 2,5 секунды, озвучка останавливается; при подтверждённой необходимости разворота старая очередь подсказок очищается и приоритет получает напоминание.
- По умолчанию озвучка использует системные голоса Windows, перечисляемые и синтезируемые в отдельном дочернем процессе; при сбое автоматически используется встроенный локальный голосовой пакет. В «Офлайн-озвучке» можно выбрать этот пакет напрямую, полностью обходя системные голоса. Прослушивание, скорость, переключатель и выбор голоса сохраняются.
- Встроенный пакет покрывает встроенные подсказки обычной навигации, WRC и числа и не требует интернета, GPU-моделей или дополнительной установки. Если свой текст легенды не покрыт пакетом, об этом прямо сообщается; для произвольного нового текста нужен работающий системный голос. Подсказки, отменённые из-за прерывания позиции, повторяются, только если ещё актуальны; уже проигранные или пройденные не повторяются.
- В 0.7.2 исправлено произношение чисел во встроенном пакете — метры, километры, дробные расстояния и дистанции WRC; при недоступном системном голосе по-прежнему происходит автоматический переход на этот пакет.

Классификация подсказок опирается на действия на перекрёстках и развилках из [официального определения Maneuver Google/Android](https://developer.android.com/reference/androidx/car/app/navigation/model/Maneuver); термины WRC, градации поворотов, слитные подсказки и упреждение — на [официальное руководство для новичков EA SPORTS WRC](https://www.ea.com/games/ea-sports-wrc/wrc-24/news/ea-sports-wrc-beginners-guide). Программа использует собственную сеть дорог и правила, не подключается к сервисам этих продуктов и не копирует их базы дорог.

При съезде с обычной дороги на бездорожье подсказка меняется на «Через N метров поверните налево на участок бездорожья» и т. п.; повторный въезд на бездорожье после пересечения обычной дороги прямо тоже объявляется. Последовательные участки бездорожья не объявляются повторно, обычная дорога под мостом не считается перекрёстком. Это работает и в обычном режиме, и в WRC; встроенный локальный голосовой пакет содержит эти подсказки.

## Голос (Yandex SpeechKit)

Голоса «Алиса» в Yandex SpeechKit нет: голос Алисы из Яндекс Навигатора через публичный API не доступен, а вырезать
записи из приложения Навигатора нельзя (авторские права и условия Яндекса). Поэтому форк использует официальный
синтез [Yandex SpeechKit API v3](https://aistudio.yandex.ru/docs/ru/speechkit/tts/voices) с похожим женским голосом:
по умолчанию `marina` с ролью `friendly`. Можно выбрать `dasha`, `jane`, `masha`, `lera`, `julia`, `omazh` и другие.

1. В Yandex Cloud создай сервисный аккаунт с ролью `ai.speechkit-tts.user` и выпусти для него API-ключ.
2. Передай ключ программе одним из способов (в репозиторий он не попадает):
   - переменная окружения: `setx YANDEX_SPEECHKIT_API_KEY "<ключ>"` (по желанию `YANDEX_SPEECHKIT_VOICE`, `YANDEX_SPEECHKIT_ROLE`, `YANDEX_SPEECHKIT_FOLDER_ID`);
   - или файл `%LOCALAPPDATA%\WardogsNavigator\speechkit.json` по образцу [`speechkit.example.json`](speechkit.example.json).
3. В настройках «Озвучка» выбери «Авто» (SpeechKit, а без ключа — голос Windows) или «Только Yandex SpeechKit».

Каждая фраза синтезируется один раз и кэшируется в WAV в `%LOCALAPPDATA%\WardogsNavigator\speechkit-cache`,
повторно уходит в кэш без сети. В Яндекс отправляется только текст подсказки.

Без ключа подсказки озвучивает офлайн-синтез Windows (SAPI) русским голосом — нужен установленный русский
речевой пакет Windows («Параметры → Время и язык → Речь»). Встроенный китайский офлайн-пакет WAV остался
в репозитории, но русские фразы произносить не умеет.

## Значок и калибровка

- Отдельный значок навигации поверх всех окон можно перетаскивать, менять его положение, ширину, высоту и прозрачность. После закрепления он пропускает мышь. Открепление и настройка выполняются в настройках главного окна; «Вернуть на основной экран» находит значок, ушедший за пределы экрана.
- В «Настройки → Поверх окон и путь на мини-карте» включаются режим «поверх всех окон» для главного окна и наложение пути, настраиваются толщина и прозрачность линии. Путь следует за областью захвата и масштабом карты, всегда пропускает мышь и не перехватывает фокус. Если система позволяет, окно пути исключается из захвата экрана; иначе при определении позиции область пути маскируется, чтобы собственный путь не участвовал в сопоставлении.
- Координаты значка задаются в логических пикселях Windows, область захвата экрана — в физических. Оптимизация полноэкранного режима Windows позволяет накладывать изображение в режиме игры «Полный экран», но не гарантирует обход композиции рабочего стола в эксклюзивном режиме. Если в текущем полноэкранном режиме значка не видно, попробуйте полноэкранный режим без рамки. Частота кадров игры и совместимость с полноэкранным режимом требуют проверки, см. [описание оптимизации полноэкранного режима от Microsoft](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/).
- Исходный масштаб расстояний вычислен по границам тайлов [открытой конфигурации карт](https://github.com/apollyon-sys/wardogs-calculator/tree/main/maps), 100 м на единицу координат и масштабированию/привязке изображений: OZETI ≈ **5,3573**, BAKURANI **5,3867**, ZESTAFONA **5,1270 м на пиксель карты**. У OZETI сохранены координаты старой карты, поэтому существующие метки не сдвинулись. Для каждой карты масштаб можно перепроверить «Калибровкой по двум точкам» или вводом напрямую.

## Конфигурация и ограничения

Дороги, избранные маршруты, легенды, опасные зоны, пункты назначения, промежуточные точки, масштаб и правила хранятся по картам и импортируются/экспортируются в UTF-8 JSON. Области экрана, озвучка и настройки значка общие. Каталог автосохранения — `%LOCALAPPDATA%\WardogsNavigator`: OZETI использует прежний `project.json`, две другие карты — `maps\bakurani\project.json` и `maps\zestafona\project.json`; `settings.json` хранит выбор карты и общие настройки. Обновление переносимой сборки не перезаписывает эти пользовательские данные. Исходные карты не изменяются, онлайн-сервисы для работы не нужны.

Программа захватывает только заданные области экрана, не читает и не изменяет память и файлы игры, ничего не внедряет в игру и не управляет машиной автоматически. Сам по себе захват экрана не гарантирует согласия разработчика игры; ориентируйтесь на [официальную политику WARDOGS](https://www.wardogs.com/enforcement) и ответы разработчика.

## Известные границы проверки

Фрагменты открытых подложек трёх карт используются для проверки сопоставления признаков, масштаба, захвата и наложения пути. В 0.6.0 дополнительно по предоставленной пользователем записи игры на ZESTAFONA проверены перетаскивание и масштабирование большой карты, а также соответствие после маскирования наложения; личная запись с исходниками не распространяется. Автотесты и воспроизведение записей не заменяют живую игру и проверку реальной проходимости. Движение, перекрытия, прозрачность карты и расхождения рельефа в реальном времени требуют проверки в игре; распознавания мин и вражеских юнитов в программе пока нет.

Если силуэт направления не распознан, показывается «Направление неизвестно», а при надёжном определении по рельефу навигация продолжается. При неудаче захвата или распознавания отдельного кадра озвучка приостанавливается, старая позиция и путь скрываются, попытки продолжаются с прежним интервалом, а после восстановления сохраняются прежние поездка и настройки рейса; заново выбирать пункт назначения не нужно. Если ресурсы карты не инициализировались или область захвата меньше 60 × 60 пикселей, захват останавливается — сначала устраните проблему, потом включайте определение позиции.

После сбоя определения через «Настройки → Сохранить диагностику определения» можно выгрузить последний неудачный кадр PNG и JSON с тем же именем за текущий сеанс — даже если позиция затем восстановилась автоматически. Если неудач не было, сохраняется последний обработанный кадр; если не удался сам захват и изображения нет, сохраняется только JSON с ошибкой — старое изображение не выдаётся за момент сбоя. JSON разделяет результат выбранного кадра, время получения и состояние определения на момент сохранения. Переключение карты, повторное включение определения или проверка новой картинки сбрасывают журнал неудач; диагностика сохраняет только выбранную пользователем область.

Локальные автотесты и тесты захвата Windows не заменяют проверку в игре. В игре нужно убедиться: позиция не прыгает, дороги проходимы, объезд опасных зон работает, подсказки разворота в режиме туда-обратно звучат, значок не мешает управлению, оба вида озвучки слышны и звучат вовремя.

## Разработка и сборка

Нужны Windows 10/11 x64 и Python 3.12. Карты и признаки для определения позиции уже входят в проект, поэтому для запуска из исходников и сборки скачивать карты не нужно. Команды выполняются в корне проекта:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
.venv\Scripts\python -m pytest -q
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

По умолчанию создаются `dist\WardogsNavigator\WardogsNavigator.exe` и `dist\WardogsNavigator-Windows-x64.zip`. Если старая версия запущена, другой каталог вывода можно задать через `-OutputDirectory dist\release`; перед запуском новой версии закройте старую, чтобы две программы не сохраняли одни и те же пользовательские данные. Сборка обновляет файлы программы в выбранном каталоге. Если окружение с зависимостями уже есть, нужный интерпретатор можно указать через `-PythonExecutable`.

Ресурсы карт и необязательные команды их пересборки описаны в [assets/README.md](assets/README.md). Программа не выходит в сеть и не строит всю сеть дорог на лету. Пересборка данных — операция сопровождения, она может изменить сеть дорог-кандидатов; для обычного использования и сборки она не нужна.

Каталоги исходников: `wardogs_nav/` — программа, `tests/` — автотесты, `tools/` — инструменты подготовки и публикации карт, `assets/` — встроенные карты, сеть дорог по умолчанию и признаки определения позиции. Правила участия — в [CONTRIBUTING.md](CONTRIBUTING.md).

Диагностика: `WardogsNavigator.exe --self-test <полный путь к отчёту.json>` проверяет упакованные ресурсы, определение позиции, построение маршрутов, опасные зоны, интерфейс и системную озвучку, создаёт отчёт и снимок окна программы. Диагностика не подключается к игре и не управляет ею. Для тестов рекомендуется задать переменную окружения `WARDOGS_NAV_DATA` с отдельным каталогом.

`python tools/export_source.py` создаёт в `dist/open-source/` самостоятельную копию исходников для запуска, тестов и сборки, а также ZIP с исходниками. Если каталог вывода уже существует, укажите новый через `--output dist/новый_каталог/WardogsNavigator` — существующий репозиторий не перезаписывается.

## Обмен конфигурациями игроков

В [библиотеке конфигураций сообщества](community/README.md) по картам можно искать и публиковать сети дорог, избранные маршруты, раллийные легенды и полные конфигурации карт. Для каждой конфигурации указываются автор, подходящая версия, описание проверки и способ импорта; игроки присылают их через PR, сопровождающий проверяет и принимает.

Пошаговые руководства для тех, кто впервые пользуется GitHub, есть только на китайском: [с иллюстрациями](community/新手投稿图文教程.md) и [текстовое](community/新手投稿纯文字教程.txt) — от экспорта файлов и регистрации до загрузки через сайт и правок по замечаниям, без установки инструментов разработки. Обе инструкции также кладутся в папку `community` собранной версии.

Сеть дорог и избранное импортируются соответствующими кнопками с объединением, а полная конфигурация заменяет текущие данные целевой карты — перед импортом сделайте резервную копию. Шаги скачивания и публикации — в описании сообщества. Библиотека конфигураций в оригинальном репозитории: [GitHub](https://github.com/greatredo/wardogs-navigator/tree/main/community). Конфигурации сообщества обновляются независимо от выпусков программы, игрок сам решает, что скачивать и импортировать.
